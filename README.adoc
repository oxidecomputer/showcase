== Status Key

[cols="1,2,5",options="header"]
|===
| Emoji | Status | Description

| ✅
| Official
| Actively maintained and documented by Oxide.

| 👀
| Preview
| Maintained by Oxide, but APIs or behavior may change.

| 📖
| Reference
| Working example without a product support commitment.

| 🧪
| Experimental
| Prototype or incomplete implementation.

| ⚠️
| Deprecated
| Still available, but replacement or removal is planned.

| 📦
| Archived
| No longer maintained.

| 👥
| Community
| Maintained outside Oxide; use alongside a maturity status
|===
